Metergroup

Barra apilada con leyenda — reparto proporcional entre varias categorías (ej. horas por área). Migrado del catálogo interno de panel-assets (.metergroup), candidato surgido de la comparación 1 a 1.

Uso básico

// las categorías se pasan como propiedad JS, no como atributos
<ui-metergroup id="meter"></ui-metergroup>

<script>
  document.getElementById('meter').segments = [
    { label: 'Backend', value: 45, variant: 'primary' },
    { label: 'Frontend', value: 30, variant: 'success' },
    { label: 'QA', value: 25, variant: 'warning' },
  ];
</script>

Props

PropTipoDefaultDescripción
segments{ label, value, variant }[][]value en porcentaje (0-100). variant: "neutral" | "primary" | "success" | "warning" | "danger" | "info" | "purple".

Slots

No tiene slots — todo el contenido sale de segments.

Eventos

No emite eventos.

Accesibilidad

  • La leyenda repite el valor numérico como texto — el color nunca es el único portador de significado.
