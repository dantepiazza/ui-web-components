Toast

Notificación que se autodescarta. Se agrega al DOM (normalmente a un contenedor fijo en una esquina) y se elimina sola después de duration ms, o al hacer click en cerrar.

Uso básico

Mostrar toast Con título 
<div id="toast-container" style="position:fixed;top:1rem;right:1rem"></div>

<script>
  // al confirmar una acción:
  const toast = document.createElement('ui-toast');
  toast.setAttribute('variant', 'success');
  toast.textContent = 'Cambios guardados';
  document.getElementById('toast-container').appendChild(toast);
</script>

Props

PropTipoDefaultDescripción
variant"info" | "success" | "warning" | "danger""info"Ícono y color asociado.
durationnumber4000Milisegundos antes de autodescartarse. 0 lo deja abierto hasta que lo cierren manualmente.
headingstring""Título opcional, en negrita, arriba del mensaje.

Slots

SlotDescripción
(default)Mensaje del toast.

Eventos

EventoDetailCuándo se emite
ui-toast-dismiss—Justo antes de que el toast se remueva solo del DOM (por timeout o por click en cerrar).

Integración

createToast(msg: string, variant = 'info') {
  const el = document.createElement('ui-toast');
  el.setAttribute('variant', variant);
  el.textContent = msg;
  this.toastContainer.nativeElement.appendChild(el);
}
<div x-data x-on:notify.window="...">
  // disparar desde Livewire con $dispatch('notify', { message, variant })
  // y crear el <ui-toast> en el handler de Alpine
</div>

Accesibilidad

  • role="status" + aria-live="polite" — se anuncia sin robar el foco.
  • El botón de cierre tiene aria-label="Cerrar".
  • 4 segundos por defecto es suficiente para leer mensajes cortos; para mensajes largos, subí duration o usá duration="0" con cierre manual.
