Forms

Select

Dropdown de selección única. Los items se declaran como ui-option hijos; como Light DOM no preserva listeners en markup reprocesado, la selección se maneja por delegación de eventos, no con onclick en cada option.

Uso básico

Argentina Brasil Chile Uruguay 
<ui-select placeholder="Elegí un país">
  <ui-option value="ar">Argentina</ui-option>
  <ui-option value="br">Brasil</ui-option>
</ui-select>

Modo "cantidad" (display="count")

Para filtros: el trigger muestra un label fijo + un badge (0 o 1) en vez del valor elegido. Es lo que usa Filter Bar internamente.

Exterior Interior 
<ui-select display="count" label="Tipo de uso">
  <ui-option value="ext">Exterior</ui-option>
</ui-select>

Props

PropTipoDefaultDescripción
valuestring""Valor seleccionado (coincide con el value de algún ui-option).
placeholderstring"Seleccionar..."Texto cuando no hay selección (modo display="value").
display"value" | "count""value""value": el trigger muestra el texto elegido. "count": muestra label + badge de cantidad (0/1) — look de "chip de filtro".
labelstring""Texto fijo del trigger en modo display="count".
namestring""Si está definido, el valor viaja con el <form> que lo contiene (se renderiza un <input type="hidden">). Un select disabled no se envía. Sin name no se renderiza ningún input. required no está soportado: validá en el servidor.
disabledbooleanfalseDeshabilita el control.

Slots

SlotDescripción
(default)Elementos ui-option — no <option> nativas: el click solo se reconoce sobre ui-option.

Eventos

EventoDetailCuándo se emite
ui-change{ value, label }Al elegir una opción.

Integración

<ui-select [value]="country" (ui-change)="country = $event.detail.value">
  <ui-option *ngFor="let c of countries" [value]="c.code">{{ c.name }}</ui-option>
</ui-select>
<ui-select value="{{ $country }}" x-on:ui-change="$wire.country = $event.detail.value">
  @foreach ($countries as $c)
    <ui-option value="{{ $c->code }}">{{ $c->name }}</ui-option>
  @endforeach
</ui-select>

Accesibilidad

  • Trigger con aria-haspopup="listbox"/aria-expanded; lista con role="listbox".
  • Se cierra con Escape y al hacer click fuera.
  • Pendiente v2: navegación completa con flechas dentro de la lista (patrón ARIA Listbox) — por ahora la apertura es por Enter/Space, la selección por click o Tab+Enter.
