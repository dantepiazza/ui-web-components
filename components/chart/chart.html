Data display

Chart

Gráfico mínimo en SVG inline, sin librería externa de gráficos. Los datos se asignan como propiedad de JS. v1: barras y línea, sin leyendas/tooltips/animación todavía.

Uso básico

<ui-chart id="chart" type="bar"></ui-chart>

<script>
  document.getElementById('chart').data = [
    { label: 'Ene', value: 40 },
    { label: 'Feb', value: 65 },
  ];
</script>

Línea

<ui-chart type="line" color="#059669"></ui-chart>

Props

PropTipoDefaultDescripción
type"bar" | "line""bar"Tipo de gráfico.
dataArray<{label, value}> (propiedad JS)[]Puntos a graficar.
heightnumber200Alto en px.
colorstring"#4f46e5"Color de las barras/línea (cualquier valor CSS de color).

Slots

No tiene slots.

Eventos

No emite eventos.

Integración

<ui-chart [type]="'bar'" [data]="monthlySales"></ui-chart>
<ui-chart x-ref="chart" x-init="$refs.chart.data = @js($monthlySales)"></ui-chart>

Accesibilidad

  • El <svg> lleva role="img" y aria-label descriptivo.
  • Pendiente v2: tabla de datos oculta (sr-only) como alternativa textual completa para lectores de pantalla — el SVG por sí solo no comunica los valores exactos.
