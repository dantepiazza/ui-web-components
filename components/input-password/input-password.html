Input Password

Campo de contraseña con botón de mostrar/ocultar.

Uso básico

<ui-input-password label="Contraseña"></ui-input-password>

Con error

<ui-input-password label="Contraseña" error="Mínimo 8 caracteres"></ui-input-password>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
valuestring""Valor del campo.
help-textstring""Texto de ayuda.
errorstring""Mensaje de error — activa el estado inválido.
disabled / requiredbooleanfalseEstados nativos.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }En cada tecleo.

Integración

<ui-input-password label="Contraseña" [value]="password"
  (ui-input)="password = $event.detail.value"></ui-input-password>
<ui-input-password label="Contraseña" wire:model="password"></ui-input-password>

Accesibilidad

  • El botón de mostrar/ocultar tiene aria-label que cambia según el estado actual.
  • <label for> asociado por id.
