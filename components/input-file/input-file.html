Input File

Campo de archivo compacto para una fila de formulario: botón + nombre del archivo elegido. Para un área de arrastrar y soltar con lista de varios archivos, usá File Upload.

Uso básico

<ui-input-file label="Currículum" accept=".pdf,.doc,.docx"></ui-input-file>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
acceptstring""Filtro de tipos, formato nativo ("image/*", ".pdf").
disabledbooleanfalseDeshabilita el control.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ file }Al elegir o quitar el archivo. file es un File o null.

Integración

<ui-input-file label="Currículum" (ui-input)="resume = $event.detail.file"></ui-input-file>
<ui-input-file label="Currículum" x-on:ui-input="$wire.upload('resume', $event.detail.file)"></ui-input-file>

Accesibilidad

  • El botón "Elegir archivo" es un <label> asociado al input real (sr-only) — clickeable y activable por teclado.
  • El botón de quitar tiene aria-label="Quitar archivo".
