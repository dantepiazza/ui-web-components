Number Input

Campo numérico con botones +/- de paso, sobre un <input type="number"> real.

Uso básico

<ui-number-input label="Cantidad" value="1" min="0" max="10"></ui-number-input>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
valuenumber0Valor actual.
min / maxnumber-∞ / ∞Límites; deshabilitan el botón correspondiente al llegar.
stepnumber1Incremento/decremento por click.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }Al cambiar el valor (botones o tecleo).

Integración

<ui-number-input [value]="qty" [max]="stock"
  (ui-input)="qty = $event.detail.value"></ui-number-input>
<ui-number-input value="{{ $qty }}" max="{{ $stock }}"
  wire:model="qty"></ui-number-input>

Accesibilidad

  • Botones +/- con aria-label ("Sumar"/"Restar"), deshabilitados nativamente al llegar a los límites.
  • <label for> asociado al input central.
