Pull to Refresh

Envolvé contenido scrolleable en <ui-pull-refresh>. En dispositivos táctiles, arrastrar hacia abajo desde el tope muestra un spinner y, pasado un umbral, dispara el evento ui-refresh (burbujea). El spinner queda girando hasta que llamás .complete() sobre el elemento — mismo flujo que el ion-refresher de Ionic.

Solo touch. Con mouse no hay gesto de pull — el contenido scrollea normal.

  <!-- lista larga -->
</ui-pull-refresh>

<script>
  feed.addEventListener('ui-refresh', async () => {
    await recargarDatos();
    feed.complete();
  });
</script>

Eventos

EventoDescripción
ui-refreshSe dispara al soltar tras pasar el umbral de arrastre. Burbujea. En el handler recargá los datos y llamá event.target.complete() al terminar.

Métodos

MétodoDescripción
.complete()Retrae el spinner y termina el estado de refresco. Obligatorio llamarlo — si no, el spinner queda para siempre.

Notas

  • El host se vuelve el contenedor de scroll (overflow-y-auto) — dale una altura acotada.
  • El gesto solo se arma cuando el scroll está en el tope (scrollTop === 0).
  • Sin <div> envolvente: solo se antepone un indicador chico; tu contenido queda intacto.
  • Da una alternativa sin gesto para refrescar (un botón), como pide WCAG 2.5.1.
