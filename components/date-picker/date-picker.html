Date Picker

Campo de fecha que abre un Calendar al hacer click.

Uso básico

<ui-date-picker label="Fecha de entrega"></ui-date-picker>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
valuestring""Fecha en formato ISO.
namestring""Si está, renderiza un <input type="hidden"> con el valor Y-m-d para enviarlo con un form / FormData.
placeholderstring"Elegir fecha"Texto cuando no hay fecha.
min / maxstring""Rango habilitado.
disabledbooleanfalseDeshabilita el control.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }Al elegir una fecha en el calendario.

Integración

<ui-date-picker label="Entrega" [value]="deliveryDate"
  (ui-input)="deliveryDate = $event.detail.value"></ui-date-picker>
<ui-date-picker label="Entrega" wire:model="deliveryDate"></ui-date-picker>

Accesibilidad

  • El trigger es un <button> con aria-* heredado del patrón de Select.
  • Se cierra con Escape y al hacer click fuera.
