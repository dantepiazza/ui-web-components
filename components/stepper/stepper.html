Stepper

Indicador de pasos numerados + panel de contenido por paso. Mismo principio de "no capturar hijos vivos" que Tabs.

Uso básico

Formulario de datos personales. Formulario de dirección de envío. Formulario de método de pago.
Atrás Siguiente 
<ui-stepper>
  <ui-step label="Datos" active>...</ui-step>
  <ui-step label="Envío">...</ui-step>
</ui-stepper>

<script>
  stepper.next();  // avanza al siguiente paso
  stepper.back();  // vuelve al paso anterior
</script>

Props — ui-step

AtributoTipoDescripción
labelstringTexto junto al círculo.
activebooleanCuál paso arranca visible.

Slots

ComponenteSlotDescripción
ui-stepper(default)Elementos ui-step.
ui-step(default)Contenido de ese paso.

Eventos / API

MiembroDescripción
ui-stepper-changeEvento con { index } al cambiar de paso.
.next() / .back()Métodos para avanzar/retroceder.

Integración

<ui-stepper #wizard (ui-stepper-change)="onStep($event.detail.index)">
  <ui-step label="Datos" active>...</ui-step>
</ui-stepper>
<ui-button (click)="wizard.next()">Siguiente</ui-button>
<ui-stepper x-ref="wizard">
  <ui-step label="Datos" active>...</ui-step>
</ui-stepper>
<button x-on:click="$refs.wizard.next()">Siguiente</button>

Accesibilidad

  • Los círculos son botones clickeables para saltar directamente a un paso.
  • El paso completado muestra un check en vez del número, doble señal (no solo color).
