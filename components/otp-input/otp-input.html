OTP Input

Un input por dígito, con avance automático de foco y soporte de pegado del código completo.

Uso básico

<ui-otp-input length="6"></ui-otp-input>

Props

PropTipoDefaultDescripción
lengthnumber6Cantidad de dígitos/cajas.
disabledbooleanfalseDeshabilita todas las cajas.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }En cada dígito ingresado.
ui-otp-complete{ value }Cuando se completan todas las cajas.

Integración

<ui-otp-input length="6" (ui-otp-complete)="verify($event.detail.value)"></ui-otp-input>
<ui-otp-input length="6"
  x-on:ui-otp-complete="$wire.verify($event.detail.value)"></ui-otp-input>

Accesibilidad

  • Cada caja tiene aria-label="Dígito N de longitud".
  • autocomplete="one-time-code" — algunos navegadores/OS ofrecen autocompletar desde el SMS recibido.
  • Backspace en una caja vacía mueve el foco a la anterior, replicando el patrón esperado de este control.
