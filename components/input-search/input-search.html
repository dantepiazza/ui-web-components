Input Search

Campo de búsqueda con ícono de lupa y botón de borrar que aparece solo cuando hay texto.

Uso básico

<ui-input-search placeholder="Buscar componentes..."></ui-input-search>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
valuestring""Texto de búsqueda.
placeholderstring"Buscar..."Placeholder.
disabledbooleanfalseDeshabilita el campo.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }En cada tecleo, y al presionar borrar (con value: "").

Integración

<ui-input-search [value]="query" (ui-input)="query = $event.detail.value"></ui-input-search>
<ui-input-search wire:model.live="query"></ui-input-search>

Accesibilidad

  • type="search" nativo — algunos lectores de pantalla lo anuncian distinto de un input de texto genérico.
  • El botón de borrar tiene aria-label="Borrar búsqueda" y devuelve el foco al campo.
