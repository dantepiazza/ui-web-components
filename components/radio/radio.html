Radio / Radio Group

ui-radio envuelve un <input type="radio"> real. ui-radio-group es opcional: agrupa varios ui-radio, les asigna el mismo name y sincroniza cuál está marcado según su prop value.

Uso básico (sin grupo)

Free Pro 
<ui-radio name="plan" value="free" checked>Free</ui-radio>
<ui-radio name="plan" value="pro">Pro</ui-radio>

Con Radio Group

Free Pro Enterprise 
<ui-radio-group name="plan" value="pro">
  <ui-radio value="free">Free</ui-radio>
  <ui-radio value="pro">Pro</ui-radio>
</ui-radio-group>

PropTipoDefaultDescripción

namestring""Grupo nativo. Si está dentro de ui-radio-group, se sobrescribe automáticamente.

Props — ui-radio-group

PropTipoDefaultDescripción

valuestring""Valor seleccionado actualmente.

Slots

ComponenteSlotDescripción

Eventos

EventoDetailCuándo se emite
ui-radio-group-change{ value }En ui-radio-group, cuando cambia la selección.

Integración

<ui-radio-group name="plan" [value]="selectedPlan"
  (ui-radio-group-change)="selectedPlan = $event.detail.value">
  <ui-radio value="free">Free</ui-radio>
</ui-radio-group>
<ui-radio-group name="plan" value="{{ $selectedPlan }}"
  x-on:ui-radio-group-change="$wire.selectedPlan = $event.detail.value">
  <ui-radio value="free">Free</ui-radio>
</ui-radio-group>

Accesibilidad

  • ui-radio-group expone role="radiogroup"; cada ui-radio es un <input type="radio"> real, así que las flechas del teclado navegan entre opciones nativamente (mismo name).
  • <label for> asociado por id en cada radio.
