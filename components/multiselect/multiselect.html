MultiSelect

Como Select, pero mantiene varias selecciones — se muestran como chips en el trigger y el menú no se cierra al elegir.

Uso básico

JavaScript PHP Lit Tailwind 
<ui-multiselect placeholder="Elegí tecnologías">
  <ui-option value="js">JavaScript</ui-option>
  <ui-option value="php">PHP</ui-option>
</ui-multiselect>

Modo "cantidad" (display="count")

Para filtros: el trigger muestra un label fijo + un badge con la cantidad elegida, en vez de los chips. El popover suma un link "Limpiar" cuando hay algo seleccionado. Es lo que usa Filter Bar internamente.

Maderas Metales Paredes 
<ui-multiselect display="count" label="Superficie">
  <ui-option value="maderas">Maderas</ui-option>
</ui-multiselect>

Props

PropTipoDefaultDescripción
placeholderstring"Seleccionar..."Texto cuando no hay selección (modo display="value").
display"value" | "count""value""value": el trigger muestra chips por cada elegido. "count": muestra label + badge con la cantidad — look de "chip de filtro".
labelstring""Texto fijo del trigger en modo display="count".
disabledbooleanfalseDeshabilita el control.

Slots

SlotDescripción
(default)Elementos ui-option.

Eventos

EventoDetailCuándo se emite
ui-change{ values }Al marcar/desmarcar una opción o quitar un chip. values es un array.

Integración

<ui-multiselect (ui-change)="skills = $event.detail.values">
  <ui-option *ngFor="let t of techs" [value]="t.id">{{ t.name }}</ui-option>
</ui-multiselect>
<ui-multiselect x-on:ui-change="$wire.skills = $event.detail.values">
  @foreach ($techs as $t)
    <ui-option value="{{ $t->id }}">{{ $t->name }}</ui-option>
  @endforeach
</ui-multiselect>

Accesibilidad

  • Lista con role="listbox" y aria-multiselectable="true".
  • Cada chip tiene su propio control de quitar independiente del trigger principal.
  • Mismo pendiente v2 que Select: navegación completa por flechas dentro de la lista.
