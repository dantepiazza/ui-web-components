Cropper

Elegí una imagen con el botón de subir sobre el marco, arrastrá para posicionar, zoom con la rueda o el slider, y confirmá con "Recortar". Componente candidato sumado a partir del catálogo interno de panel-assets (sección 7 del brief) — no forma parte de PrimeNG/Web Awesome/Flux.

Uso básico

<ui-cropper aspect-ratio="1"></ui-cropper>

<script>
  // al hacer click en "Recortar":
  cropper.addEventListener('ui-cropper-apply', (e) => {
    const dataUrl = e.detail.dataURL;
  });
</script>

Props

PropTipoDefaultDescripción
aspect-rationumber1Relación de aspecto del marco de recorte (1 = cuadrado, 1.78 ≈ 16:9).
output-sizenumber400Ancho en px del canvas de salida.

Slots

No tiene slots.

Eventos / API

MiembroDescripción
ui-cropper-changeEvento con { zoom, offsetX, offsetY } en cada pan/zoom.
ui-cropper-applyEvento con { dataURL } al hacer click en "Recortar".
.getCroppedDataURL()Renderiza el recorte actual a un canvas offscreen y devuelve un data: URL (PNG). Es lo que usa el botón "Recortar" internamente — llamalo directo si preferís tu propio botón.

Integración

<ui-cropper #cropper aspect-ratio="1"></ui-cropper>
<ui-button (click)="save(cropper.getCroppedDataURL())">Confirmar</ui-button>
<ui-cropper x-ref="cropper" aspect-ratio="1"></ui-cropper>
<button x-on:click="$wire.save($refs.cropper.getCroppedDataURL())">Confirmar</button>

Accesibilidad

  • El slider de zoom es un <input type="range"> real, operable por teclado incluso si el drag no lo es.
  • Pendiente v2: el arrastre de posicionamiento es solo mouse/touch (pointer events) — no hay alternativa por teclado para el paneo todavía.
  • touch-action: none en el área de recorte evita que el drag haga scroll de la página en mobile.
