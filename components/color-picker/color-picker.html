Color Picker

Selector de color nativo emparejado con un input de texto hexadecimal sincronizado.

Uso básico

<ui-color-picker label="Color de marca" value="#4f46e5"></ui-color-picker>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
valuestring"#4f46e5"Color en formato hex (#rrggbb).
disabledbooleanfalseDeshabilita ambos controles.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }Al cambiar el color desde cualquiera de los dos controles.

Integración

<ui-color-picker label="Marca" [value]="brandColor"
  (ui-input)="brandColor = $event.detail.value"></ui-color-picker>
<ui-color-picker label="Marca" value="{{ $brandColor }}" wire:model="brandColor"></ui-color-picker>

Accesibilidad

  • El input type="color" nativo trae su propio selector accesible del sistema operativo.
  • El input de texto permite escribir el hex directamente, para quien prefiera no usar el selector visual.
