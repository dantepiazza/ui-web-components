Data Grid

Las columnas se declaran en HTML; las filas se asignan como propiedad de JS (grid.rows = [...]), porque los datos tabulares normalmente vienen de una API, no de markup. v1: ordenar por columna. Sin paginación/virtualización/edición de celda todavía — combinalo con Pagination por fuera.

Uso básico

<ui-data-grid id="grid">
  <ui-data-grid-column field="name" label="Nombre" sortable></ui-data-grid-column>
  <ui-data-grid-column field="email" label="Email"></ui-data-grid-column>
</ui-data-grid>

<script>
  document.getElementById('grid').rows = [
    { name: 'Dante Herrera', email: 'dante@ej.com', role: 'Admin' },
    { name: 'Maria Lopez', email: 'maria@ej.com', role: 'Editor' },
  ];
</script>

Props — ui-data-grid

PropTipoDefaultDescripción
rowsArray<object> (propiedad JS)[]Filas, cada una un objeto con una key por field de columna.

Props — ui-data-grid-column

AtributoTipoDescripción
fieldstringKey del objeto de fila a mostrar en esta columna.
labelstringTexto del header. Si se omite, usa field.
sortablebooleanHabilita ordenar al hacer click en el header.

Slots

SlotDescripción
(default)Elementos ui-data-grid-column — se leen una sola vez al conectar.

Eventos

No emite eventos propios en v1 (el ordenamiento es interno).

Integración

<ui-data-grid [rows]="users">
  <ui-data-grid-column field="name" label="Nombre" sortable></ui-data-grid-column>
</ui-data-grid>
// property binding, no atributo — .rows es un array de JS
<ui-data-grid x-ref="grid" x-init="$refs.grid.rows = @js($users)">
  <ui-data-grid-column field="name" label="Nombre" sortable></ui-data-grid-column>
</ui-data-grid>

Accesibilidad

  • <table> semántica real, con <th> para headers.
  • Headers ordenables tienen un ícono visual del sentido de orden actual, no solo color/estado interno.
