Rich Text Editor

Editor WYSIWYG mínimo: una región contenteditable con una toolbar simple sobre document.execCommand. Es una API deprecada pero todavía ampliamente soportada — es la opción más simple que funciona para v1; un editor "de verdad" (basado en modelo de contenido, tipo ProseMirror) es un proyecto más grande para una versión futura.

Uso básico

Texto inicial con negrita.

 
<ui-rich-text-editor>
  <p>Texto inicial con <b>negrita</b>.</p>
</ui-rich-text-editor>

Props

PropTipoDefaultDescripción
placeholderstring"Escribí acá..."Texto cuando el editor está vacío.

Slots

SlotDescripción
(default)HTML inicial del editor.

Eventos / API

MiembroDescripción
ui-inputEvento con { value } (el HTML actual) en cada tecleo.
.valueGetter con el HTML actual.

Integración

<ui-rich-text-editor (ui-input)="body = $event.detail.value">
  <div [innerHTML]="initialBody"></div>
</ui-rich-text-editor>
<ui-rich-text-editor x-on:ui-input="$wire.body = $event.detail.value">
  {!! $initialBody !!}
</ui-rich-text-editor>

Accesibilidad

  • Los botones de la toolbar tienen aria-label y no roban el foco del editor (mousedown con preventDefault).
  • document.execCommand está deprecada en la spec, aunque sigue funcionando en todos los navegadores mayores — no hay reemplazo estándar estable todavía, por eso la decisión consciente de usarla en v1.
  • Contenido pegado desde otras fuentes (Word, Google Docs) puede traer estilos inline no deseados — no hay sanitización en v1.
