Time Picker

Envuelve un <input type="time"> nativo — la UI del selector la aporta el navegador/sistema operativo.

Uso básico

<ui-time-picker label="Hora de inicio" value="09:00"></ui-time-picker>

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible.
valuestring""Hora en formato HH:mm.
disabled / requiredbooleanfalseEstados nativos.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }Al cambiar la hora.

Integración

<ui-time-picker label="Inicio" [value]="startTime"
  (ui-input)="startTime = $event.detail.value"></ui-time-picker>
<ui-time-picker label="Inicio" wire:model="startTime"></ui-time-picker>

Accesibilidad

  • Al ser un control nativo, hereda toda la accesibilidad del sistema operativo/navegador para selección de hora.
  • <label for> asociado por id.
