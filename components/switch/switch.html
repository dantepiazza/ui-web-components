Switch

Toggle booleano, construido sobre un <input type="checkbox"> real (visualmente oculto) para soporte de teclado nativo.

Uso básico

Notificaciones por email Modo oscuro Opción no disponible 
<ui-switch>Notificaciones por email</ui-switch>
<ui-switch checked>Modo oscuro</ui-switch>

Esperando confirmación (async)

Sincronizando con el servidor... 
<ui-switch loading>Sincronizando...</ui-switch>

<script>
  // al togglear: switchEl.loading = true; await fetch(...); switchEl.loading = false;
</script>

Props

PropTipoDefaultDescripción
checkedbooleanfalseEstado activado.
disabledbooleanfalseDeshabilita el control.
loadingbooleanfalseMuestra un spinner adentro del círculo y bloquea el input — para cuando activar el switch dispara una llamada async y hay que esperar la respuesta antes de confirmar visualmente el nuevo estado.
namestring""Nombre del campo en un <form>.

Slots

SlotDescripción
(default)Texto de la etiqueta.

Eventos

EventoDetailCuándo se emite
ui-change{ checked }Al cambiar el estado.

Integración

<ui-switch [checked]="darkMode" (ui-change)="darkMode = $event.detail.checked">
  Modo oscuro
</ui-switch>
<ui-switch name="dark_mode" wire:model="darkMode">
  Modo oscuro
</ui-switch>

Accesibilidad

  • Es un <input type="checkbox"> real (visualmente oculto vía opacidad, no display:none) — lectores de pantalla lo anuncian como checkbox, patrón aceptado para switches simples.
  • Foco visible en el track vía peer-focus-visible:outline.
  • <label for> asociado — click en el texto también activa el control.
