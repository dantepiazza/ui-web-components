Data display

Flag

Bandera de país a partir de un código ISO 3166-1 alpha-2. Los países con SVG propio (hoy solo AR, a modo de referencia — el resto queda como deuda pendiente) se ven idénticos en cualquier navegador/SO; todo lo demás cae al emoji nativo, que en Windows suele mostrarse como las dos letras del código en vez del gráfico.

Uso básico

Arriba: AR es SVG real, el resto es fallback a emoji (en Windows se ve como texto — es la deuda pendiente).

<ui-flag country="AR"></ui-flag>

Tamaños

<ui-flag country="AR" size="lg"></ui-flag>

Props

PropTipoDefaultDescripción
countrystring""Código ISO 3166-1 alpha-2 ("AR", "BR", etc). Case-insensitive.
size"sm" | "md" | "lg""md"Tamaño del emoji.

Slots

No tiene slots.

Eventos

No emite eventos. Si country no es un código válido, loguea un warning y no renderiza nada.

Integración

<ui-flag [country]="user.countryCode"></ui-flag>
<ui-flag country="{{ $user->country_code }}"></ui-flag>

Accesibilidad

  • role="img" con aria-label="Bandera de XX" — los emoji de bandera no siempre se anuncian de forma clara por sí solos en todos los lectores de pantalla.
  • Requiere que el sistema operativo/fuente tenga soporte de emoji de bandera (universal en iOS/Android/macOS; Windows lo soporta desde Windows 11 — en Windows 10 puede mostrar el código de país en texto en vez del gráfico).
