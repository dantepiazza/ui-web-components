Foundation

Icon

Renderiza un ícono SVG en línea a partir de un set incorporado, con tamaño y color controlados por CSS (currentColor).

Uso básico

<ui-icon name="check"></ui-icon>

Tamaños

<ui-icon name="star" size="sm"></ui-icon>
<ui-icon name="star" size="lg"></ui-icon>

Color heredado

<span class="text-rose-600">
  <ui-icon name="heart"></ui-icon>
</span>

Props

PropTipoDefaultDescripción
namestring"info"Nombre del ícono del set incorporado (ver listado al final). Si no coincide con ninguno, se asume que son clases de una fuente de íconos externa y se renderiza un <i> con esas clases — ver "Fuentes de íconos externas" debajo.
size"sm" | "md" | "lg""md"Tamaño del ícono. Con el set incorporado: 16px / 20px / 24px de SVG. Con una fuente externa: text-base / text-lg / text-xl.

Fuentes de íconos externas

Si name no coincide con ningún ícono del set incorporado, se trata como una o más clases CSS de una fuente de íconos que ya tengas cargada en la página (PrimeIcons, Font Awesome, Material Icons, etc.) y se renderiza un <i> con esas clases en vez de un SVG inline. No hace falta que la librería conozca esa fuente — solo cargá su CSS en tu proyecto.

<ui-icon name="pi pi-moon"></ui-icon>
<ui-icon name="fab fa-instagram"></ui-icon>

Slots

No tiene slots.

Eventos

No emite eventos. Si name no existe en el set, loguea un warning en consola y no renderiza nada.

Integración

<ui-icon name="check" size="lg"></ui-icon>

// schemas: [CUSTOM_ELEMENTS_SCHEMA] en el módulo consumidor
{{-- resources/views/components/... --}}
<button class="btn-primary">
  <ui-icon name="check"></ui-icon> Guardar
</button>

Accesibilidad

  • Se renderiza con aria-hidden="true" — es decorativo por defecto.
  • Si el ícono transmite significado (ej. único contenido de un botón), envolvé el control con aria-label en el elemento interactivo, no en el ícono.
  • Hereda color vía currentColor, así que el contraste depende del contenedor — validalo caso a caso.
