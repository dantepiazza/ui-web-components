Dialog

Caja de diálogo centrada, construida sobre <dialog> nativo (showModal()) — foco atrapado, capa superior y cierre con Escape los da el navegador gratis. El contenido va en un <template>, así que sobrevive intacto entre aperturas. Es para mensajes, confirmaciones y a lo sumo un form chico — siempre se ve como una caja de diálogo, nunca pantalla completa ni drawer. Si necesitás contenido libre (cualquier HTML) y/o un panel que se deslice desde un borde, usá Modal — son componentes distintos a propósito.

Uso básico (centrado)

Abrir dialog 
<ui-dialog id="demo-dialog">
  <template>
    <h3>Confirmar acción</h3>
    <ui-button id="dialog-cancel">Cancelar</ui-button>
  </template>
</ui-dialog>

<script>
  document.getElementById('dialog-trigger').onclick = () =>
    document.getElementById('demo-dialog').show();
</script>

Confirm / Prompt (API por JS, sin markup)

Para el caso común de "confirmá esto" / "pedí un valor corto" no hace falta armar un <template> — UiDialog.confirm() y UiDialog.prompt() arman un ui-dialog al vuelo, lo muestran, y devuelven una Promise. Si no importaste la clase (bundle clásico), usá los atajos window.__uiwc.confirm() / .prompt().

Eliminar producto Renombrar 

// devuelve Promise<boolean>
const ok = await window.__uiwc.confirm('¿Eliminar este producto?', {
  title: 'Confirmar acción',
  confirmLabel: 'Eliminar',
  variant: 'danger',
});

// devuelve Promise<string | null> (null si cancelan)
const nombre = await window.__uiwc.prompt('Nuevo nombre:', { value: 'Producto A' });

Integración

<ui-button (click)="dialog.show()">Eliminar</ui-button>
<ui-dialog #dialog (ui-dialog-close)="onClose()">
  <template>...</template>
</ui-dialog>
<ui-dialog x-ref="dialog">
  <template>...</template>
</ui-dialog>
<button x-on:click="$refs.dialog.show()">Eliminar</button>

¿Dialog o Modal?

  • Dialog (acá) — mensaje, confirmación, o un form chico que SIEMPRE se ve como una caja de diálogo centrada. Nunca cambia de forma según el viewport. Trae confirm()/prompt() de regalo.
  • Modal — panel de contenido libre (cualquier HTML), puede ser centrado o drawer izquierdo/derecho, y pasa a pantalla completa en mobile. No impone título/cuerpo/footer.

Accesibilidad

  • showModal() nativo: foco atrapado dentro del dialog, Escape cierra, el resto de la página queda inert automáticamente.
  • El foco vuelve al elemento que abrió el dialog al cerrarse (comportamiento nativo del navegador).
  • Click en el backdrop (fuera del contenido) cierra el modal.
  • confirm()/prompt() ponen el foco inicial en el botón de confirmar / el input, respectivamente.
