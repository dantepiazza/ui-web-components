Kanban

Tablero con columnas y tarjetas arrastrables con mouse, touch y teclado. Pensado para convivir con cualquier stack: el HTML que renderiza tu servidor o framework es el que queda — el tablero solo agrega clases, atributos y listeners delegados, y te avisa con eventos cancelables.

Uso básico

Arrastrá entre columnas y dentro de una columna. Con teclado: foco en una tarjeta → Espacio para levantarla, flechas para moverla, Espacio/Enter para soltar, Esc para cancelar. En touch: mantené apretada la tarjeta ~0,2 s y arrastrá.

Eventos

Se emiten en el ui-kanban (burbujean), son cancelables, y los ids viajan como strings tal cual los pusiste en card-id / column-id (sin asumir prefijos). El detail trae el orden completo resultante de cada columna afectada, así persistir es una sola llamada.

EventoDetailCuándo se emite
ui-kanban-move{ cardId, card, fromColumnId, toColumnId, fromOrderedIds, toOrderedIds, index }La tarjeta cambió de columna. index es su posición en la destino.
ui-kanban-sort{ cardId, card, columnId, orderedIds, index }La tarjeta se reordenó dentro de su misma columna (si soltás en el mismo lugar, no se emite).
ui-kanban-card-click{ cardId, card }Click o Enter en una tarjeta con clickable (no se dispara al terminar un arrastre).

¿Quién mueve el DOM? (controlled)

ModoComportamiento
(default)Al soltar, el tablero mueve el nodo (UI optimista). event.preventDefault() cancela el movimiento; board.revert() lo deshace después (ej. el servidor lo rechazó asíncronamente). Para Livewire/Blade, HTMX, vanilla.
controlledEl tablero nunca toca el DOM: solo emite. Actualizás tu estado y el framework re-renderiza. Para React, Angular, Vue, Svelte — mover a mano un nodo que el framework posee lo desincroniza.

Slots

Son atributos slot="…" sobre hijos normales (light DOM): se ubican por CSS, nada se mueve ni se captura, así tu framework puede re-renderlos libremente. Lo que no lleve slot se muestra tal cual.

Integración

<ui-kanban
  x-on:ui-kanban-move="$wire.moved($event.detail.cardId, $event.detail.toColumnId, $event.detail.toOrderedIds, $event.detail.fromOrderedIds)"
  x-on:ui-kanban-sort="$wire.sorted($event.detail.columnId, $event.detail.orderedIds)">
  @foreach ($columns as $col)
    <ui-kanban-column wire:key="col-{{ $col->id }}" column-id="{{ $col->id }}" label="{{ $col->name }}">
      @foreach ($col->cards as $c)
        <ui-kanban-card wire:key="card-{{ $c->id }}" card-id="{{ $c->id }}">
          <span slot="title">{{ $c->title }}</span>
        </ui-kanban-card>
      @endforeach
    </ui-kanban-column>
  @endforeach
</ui-kanban>
<!-- Modo default: el tablero mueve el nodo y morphdom lo reconcilia por wire:key.
     Un re-render durante un arrastre (wire:poll) no lo interrumpe: lo arrastrado es un clon. -->
<ui-kanban controlled (ui-kanban-move)="onMove($event.detail)" (ui-kanban-sort)="onSort($event.detail)">
  <ui-kanban-column *ngFor="let col of columns; trackBy: byId" [attr.column-id]="col.id" [attr.label]="col.name">
    <ui-kanban-card *ngFor="let c of col.cards; trackBy: byId" [attr.card-id]="c.id">
      <span slot="title">{{ c.title }}</span>
    </ui-kanban-card>
  </ui-kanban-column>
</ui-kanban>
// onMove(d): actualizá el estado con d.fromOrderedIds / d.toOrderedIds — Angular re-renderiza.
const ref = useRef(null);
useEffect(() => {
  const el = ref.current;
  const onMove = (e) => setBoard(applyMove(e.detail)); // usa toOrderedIds / fromOrderedIds
  const onSort = (e) => setBoard(applySort(e.detail));
  el.addEventListener('ui-kanban-move', onMove);
  el.addEventListener('ui-kanban-sort', onSort);
  return () => { el.removeEventListener('ui-kanban-move', onMove); el.removeEventListener('ui-kanban-sort', onSort); };
}, []);

<ui-kanban ref={ref} controlled>
  {columns.map(col => (
    <ui-kanban-column key={col.id} column-id={col.id} label={col.name}>
      {col.cards.map(c => (
        <ui-kanban-card key={c.id} card-id={c.id}><span slot="title">{c.title}</span></ui-kanban-card>
      ))}
    </ui-kanban-column>
  ))}
</ui-kanban>
<ui-kanban controlled @ui-kanban-move="onMove($event.detail)" @ui-kanban-sort="onSort($event.detail)">
  <ui-kanban-column v-for="col in columns" :key="col.id" :column-id="col.id" :label="col.name">
    <ui-kanban-card v-for="c in col.cards" :key="c.id" :card-id="c.id">
      <span slot="title">{{ c.title }}</span>
    </ui-kanban-card>
  </ui-kanban-column>
</ui-kanban>

Rechazar un movimiento

// síncrono: no se mueve nada
board.addEventListener('ui-kanban-move', (e) => { if (!allowed(e.detail)) e.preventDefault(); });

// asíncrono (default mode): se movió optimista; si el server dice que no…
board.addEventListener('ui-kanban-move', async (e) => {
  const ok = await save(e.detail);
  if (!ok) board.revert();
});

Accesibilidad

  • Cada tarjeta es focusable (tabindex="0"). Espacio la levanta, flechas la mueven (↑↓ posición, ←→ columna), Espacio/Enter la suelta, Esc cancela. Cada paso se anuncia en una región aria-live.
  • Touch: arrastre tras un mantenido corto, así el scroll del tablero y de la página siguen funcionando.
  • Si necesitás ordenar sin arrastre, usá readonly y ofrecé tus propios botones/menú que actualicen el estado.
