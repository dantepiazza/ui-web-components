Data display

Kanban

Tablero con columnas y tarjetas arrastrables, sobre la API nativa HTML5 Drag and Drop — sin librería externa.

Uso básico

Diseñar la página de precios Escribir tests del checkout Migrar a Tailwind v4 Setup del repo 
<ui-kanban>
  <ui-kanban-column label="Por hacer">
    <ui-kanban-card>Diseñar la página de precios</ui-kanban-card>
  </ui-kanban-column>
  <ui-kanban-column label="Hecho"></ui-kanban-column>
</ui-kanban>

Props — ui-kanban-column

AtributoTipoDescripción
labelstringTítulo de la columna.

Slots

ComponenteSlotDescripción
ui-kanban(default)Elementos ui-kanban-column.
ui-kanban-column(default)Elementos ui-kanban-card.
ui-kanban-card(default)Contenido de la tarjeta.

Eventos

EventoDetailCuándo se emite
ui-kanban-move{ cardId }En la columna destino, cuando se suelta una tarjeta en ella.

Integración

<ui-kanban>
  <ui-kanban-column *ngFor="let col of columns" [label]="col.name"
    (ui-kanban-move)="onMove(col.id, $event.detail.cardId)">
    <ui-kanban-card *ngFor="let c of col.cards" [id]="c.id">{{ c.title }}</ui-kanban-card>
  </ui-kanban-column>
</ui-kanban>
<ui-kanban>
  @foreach ($columns as $col)
    <ui-kanban-column label="{{ $col->name }}" x-on:ui-kanban-move="$wire.move('{{ $col->id }}', $event.detail.cardId)">
      @foreach ($col->cards as $c)
        <ui-kanban-card id="{{ $c->id }}">{{ $c->title }}</ui-kanban-card>
      @endforeach
    </ui-kanban-column>
  @endforeach
</ui-kanban>

Accesibilidad

  • El drag and drop nativo (HTML5) es solo con mouse por defecto — no accesible por teclado ni touch en todos los navegadores.
  • Pendiente v2: una alternativa por teclado (ej. menú "Mover a..." en cada tarjeta) para no depender exclusivamente del arrastre.
