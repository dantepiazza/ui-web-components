Navigation

Breadcrumb

Rastro de navegación con separador automático entre items (CSS puro, sin importar cuántos haya).

Uso básico

Inicio Componentes Breadcrumb 
<ui-breadcrumb>
  <a href="/">Inicio</a>
  <a href="/docs">Componentes</a>
  <span>Breadcrumb</span>
</ui-breadcrumb>

Props

No tiene props.

Slots

SlotDescripción
(default)<a> para cada nivel navegable; <span> para el nivel actual (no clickeable).

Eventos

No emite eventos — los links son <a> reales.

Integración

<ui-breadcrumb>
  <a *ngFor="let c of crumbs" [routerLink]="c.url">{{ c.label }}</a>
</ui-breadcrumb>
<ui-breadcrumb>
  @foreach ($crumbs as $c)
    <a href="{{ $c->url }}">{{ $c->label }}</a>
  @endforeach
</ui-breadcrumb>

Accesibilidad

  • <nav aria-label="Breadcrumb"> con lista <ol> semántica.
  • El último item se distingue visualmente (negrita) pero además debería ser un <span>, no un link, ya que representa la página actual.
