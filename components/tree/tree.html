Data display

Tree

Lista jerárquica expandible. ui-tree-item es recursivo — anidá tantos niveles como necesites.

Uso básico

<ui-tree>
  <ui-tree-item label="src">
    <ui-tree-item label="button.js"></ui-tree-item>
  </ui-tree-item>
  <ui-tree-item label="package.json"></ui-tree-item>
</ui-tree>

Props — ui-tree-item

Prop (atributo)TipoDescripción
labelstringTexto del nodo. El chevron de expandir aparece solo si tiene ui-tree-item anidados.

Slots

ComponenteSlotDescripción
ui-tree(default)Elementos ui-tree-item de nivel raíz.
ui-tree-item(default)ui-tree-item anidados (opcional).

Eventos

EventoDetailCuándo se emite
ui-tree-select{ label }Al hacer click en un nodo. ui-tree deselecciona automáticamente los demás.

Integración

<ui-tree (ui-tree-select)="onSelect($event.detail.label)">
  <ui-tree-item *ngFor="let n of nodes" [label]="n.name"></ui-tree-item>
</ui-tree>
<ui-tree>
  @foreach ($nodes as $n)
    <ui-tree-item label="{{ $n->name }}"></ui-tree-item>
  @endforeach
</ui-tree>

Accesibilidad

  • ui-tree expone role="tree"; cada nodo role="treeitem" con aria-expanded/aria-selected.
  • Cada header de nodo es enfocable (tabindex="0").
  • Pendiente v2: navegación completa con flechas arriba/abajo/izquierda/derecha entre nodos (patrón ARIA Tree) — por ahora la navegación es por Tab normal.
