Kanban Label

Chip cuyo color viene de un dato (cualquier color CSS, por ejemplo una etiqueta con color elegido por el usuario y guardado en base). Fondo al ~13% del color y texto del color — se lee bien en claro y en oscuro. Vive junto al Kanban pero no depende de él: sirve donde necesites un chip con color en tiempo de ejecución, algo que los variant fijos de Tag y Badge no pueden.

Uso básico

Diseño Web Dev Urgente Cualquier color CSS Sin color 
<ui-kanban-label color="#7c3aed">Diseño</ui-kanban-label>
<!-- el color viene del dato: -->
<ui-kanban-label color="{{ $label->color }}">{{ $label->name }}</ui-kanban-label>

Props

PropTipoDefaultDescripción

remove-classstring—Saca clases propias puntuales — convención de toda la librería.

Accesibilidad

  • El color solo no debe transmitir el significado: el texto de la etiqueta siempre dice lo que es.
  • Con colores muy claros (amarillo, celeste pálido) el texto del mismo color pierde contraste — elegí tonos medios u oscuros.
