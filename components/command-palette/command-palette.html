Overlays

Command Palette

Overlay global tipo "Cmd+K": Ctrl+K (o Cmd+K en Mac) en cualquier parte de la página lo abre, con un buscador que filtra comandos.

Uso básico

Probá presionar Ctrl + K en esta página.

Nuevo archivo Nueva carpeta Abrir configuración Cerrar sesión 
<ui-command-palette>
  <ui-command value="new-file">Nuevo archivo</ui-command>
  <ui-command value="settings">Abrir configuración</ui-command>
</ui-command-palette>

Props

No tiene props — el atajo es siempre Ctrl/Cmd+K en v1.

Slots

SlotDescripción
(default)Comandos — se leen una sola vez al conectar (no reactivo a cambios posteriores).

Eventos

EventoDetailCuándo se emite
ui-command-select{ value, label }Al elegir un comando (click o Enter).

Integración

<ui-command-palette (ui-command-select)="runCommand($event.detail.value)">
  <ui-command *ngFor="let c of commands" [value]="c.id">{{ c.label }}</ui-command>
</ui-command-palette>
<ui-command-palette x-on:ui-command-select="$wire.run($event.detail.value)">
  @foreach ($commands as $c)
    <ui-command value="{{ $c->id }}">{{ $c->label }}</ui-command>
  @endforeach
</ui-command-palette>

Accesibilidad

  • Foco automático en el input de búsqueda al abrir.
  • Flechas arriba/abajo navegan, Enter ejecuta, Escape cierra.
  • Solo un atajo global por página — si hay más de un ui-command-palette montado a la vez, el último definido gana el listener (evitar montar más de uno).
