Empty State

Placeholder centrado para una lista, tabla o búsqueda sin resultados. Migrado del catálogo interno de panel-assets (.empty-state), candidato surgido de la comparación 1 a 1.

Uso básico

<ui-empty-state icon="folder" title="Sin resultados"
  desc="No encontramos nada que coincida con tu búsqueda.">
</ui-empty-state>

Con acción

Invitar postulante 
<ui-empty-state icon="users" title="Sin postulantes todavía">
  <ui-button size="sm">Invitar postulante</ui-button>
</ui-empty-state>

Props

PropTipoDefaultDescripción
iconstring"folder"Nombre de un ícono del set de Icon.
titlestring""Título corto.
descstring""Descripción de una línea.

Slots

SlotDescripción
(default)Acción opcional debajo del texto (ej. un ui-button).

Eventos

No emite eventos.

Accesibilidad

  • El ícono es decorativo; título y descripción son texto real.
  • Si incluís una acción, es un <button> nativo (vía ui-button) — navegable por teclado sin configuración extra.
