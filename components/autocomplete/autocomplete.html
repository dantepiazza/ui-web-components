AutoComplete

Input de texto que filtra una lista de opciones a medida que escribís (coincidencia de substring, client-side). Como Select, pero navegable por texto en vez de solo por click.

Uso básico

Argentina Brasil Chile Colombia México Uruguay 
<ui-autocomplete placeholder="Buscar país...">
  <ui-option value="ar">Argentina</ui-option>
  <ui-option value="br">Brasil</ui-option>
</ui-autocomplete>

Props

PropTipoDefaultDescripción
valuestring""Valor seleccionado.
placeholderstring"Buscar..."Placeholder del input.
disabledbooleanfalseDeshabilita el control.

Slots

SlotDescripción
(default)Opciones — se leen una sola vez al conectar (no reactivo a cambios posteriores del DOM).

Eventos

EventoDetailCuándo se emite
ui-input{ value }En cada tecleo (texto libre, no necesariamente una opción válida todavía).
ui-change{ value, label }Al elegir una opción de la lista.

Integración

<ui-autocomplete (ui-change)="country = $event.detail.value">
  <ui-option *ngFor="let c of countries" [value]="c.code">{{ c.name }}</ui-option>
</ui-autocomplete>
<ui-autocomplete x-on:ui-change="$wire.country = $event.detail.value">
  @foreach ($countries as $c)
    <ui-option value="{{ $c->code }}">{{ $c->name }}</ui-option>
  @endforeach
</ui-autocomplete>

Accesibilidad

  • role="combobox" con aria-expanded/aria-autocomplete="list"; resultados con role="listbox"/role="option".
  • Flechas arriba/abajo navegan resultados, Enter selecciona, Escape cierra.
  • Filtrado 100% client-side en v1 — para listas grandes o búsqueda server-side, hay que extenderlo (no incluido todavía).
