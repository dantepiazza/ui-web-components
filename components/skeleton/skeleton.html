Skeleton

Bloque placeholder animado, para mostrar mientras carga el contenido real.

Uso básico

<ui-skeleton variant="text"></ui-skeleton>

Variantes

<ui-skeleton variant="circle" width="3rem" height="3rem"></ui-skeleton>

Props

PropTipoDefaultDescripción
variant"text" | "circle" | "rect""text"Forma del placeholder.
widthstring""Ancho CSS explícito (ej. "3rem"). Sin esto, ocupa el 100% del contenedor.
heightstring""Alto CSS explícito. variant="text" ya trae un alto de línea por defecto.

Slots

No tiene slots.

Eventos

No emite eventos.

Integración

<ui-skeleton *ngIf="loading" variant="text"></ui-skeleton>
<div wire:loading>
  <ui-skeleton variant="text"></ui-skeleton>
</div>

Accesibilidad

  • Se renderiza con role="presentation" y aria-hidden="true" — no distrae a lectores de pantalla con contenido irrelevante.
  • El contenido real cargado debe reemplazar completamente el skeleton, no solapar.
