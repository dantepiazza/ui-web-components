Forms

Pillbox

Input de texto libre multi-valor: Enter o , agrega un chip, Backspace con el campo vacío borra el último.

Uso básico

<ui-pillbox placeholder="Agregar skill..."></ui-pillbox>

Props

PropTipoDefaultDescripción
placeholderstring"Agregar..."Placeholder del campo, solo visible sin valores.
value (atributo inicial)string""Lista separada por comas para precargar valores (solo se lee al conectar, no reactivo después).
disabledbooleanfalseDeshabilita el control.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-pillbox-change{ values }Al agregar o quitar un valor. values es un array de strings.

Integración

<ui-pillbox placeholder="Agregar skill..."
  (ui-pillbox-change)="skills = $event.detail.values"></ui-pillbox>
<ui-pillbox value="{{ implode(',', $skills) }}"
  x-on:ui-pillbox-change="$wire.skills = $event.detail.values"></ui-pillbox>

Accesibilidad

  • Cada botón de quitar tiene aria-label="Quitar {valor}".
  • El campo de texto siempre queda accesible por Tab, independientemente de cuántos chips haya.
