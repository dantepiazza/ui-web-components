Accordion

ui-accordion agrupa varios ui-accordion-item y, salvo que uses multiple, cierra los demás al abrir uno. No captura ni reprocesa el contenido de los items — pueden tener formularios u otros componentes adentro sin perder estado.

Uso básico

Con npm install @ui-web-components/components, o linkeando el script+CSS compilado. Sí — el modo script+CSS compilado no requiere pipeline de build del lado consumidor. MIT. 
<ui-accordion>
  <ui-accordion-item label="¿Cómo instalo?" open>
    Con npm install...
  </ui-accordion-item>
  <ui-accordion-item label="¿Funciona sin build?">
    Sí...
  </ui-accordion-item>
</ui-accordion>

Props — ui-accordion

PropTipoDefaultDescripción
multiplebooleanfalsePermite varios items abiertos a la vez. Por defecto, abrir uno cierra los demás.

Props — ui-accordion-item

PropTipoDefaultDescripción
labelstring""Título del header, clickeable.
openbooleanfalseEstado expandido.

Slots

ComponenteSlotDescripción
ui-accordion(default)Elementos ui-accordion-item.
ui-accordion-item(default)Contenido del panel.

Eventos

EventoDetailCuándo se emite
ui-accordion-toggle{ open }En ui-accordion-item, al abrir/cerrar.

Integración

<ui-accordion>
  <ui-accordion-item *ngFor="let f of faqs" [label]="f.question">
    {{ f.answer }}
  </ui-accordion-item>
</ui-accordion>
<ui-accordion>
  @foreach ($faqs as $f)
    <ui-accordion-item label="{{ $f->question }}">{{ $f->answer }}</ui-accordion-item>
  @endforeach
</ui-accordion>

Accesibilidad

  • Header como <button> dentro de <h3>, con aria-expanded y aria-controls apuntando al panel.
  • El panel tiene role="region" y se oculta con el atributo hidden nativo (no solo display:none por CSS).
  • Navegable por teclado como cualquier botón (Tab, Enter/Space).
