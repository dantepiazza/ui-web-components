Como Badge, pero pensado para colecciones editables (filtros, chips de input): admite un botón de quitar opcional.

Removible

Angular Livewire Lit 
<ui-tag removable variant="primary">Angular</ui-tag>

<script>
  // escuchá el evento ui-tag-remove en el contenedor
  container.addEventListener('ui-tag-remove', (e) => {
    e.target.remove();
  });
</script>

Eventos

EventoDetailCuándo se emite
ui-tag-remove—Al hacer click en el botón de quitar. Bubbles + composed: escuchalo en cualquier ancestro. El componente no se remueve solo del DOM — es responsabilidad de quien lo consume.

Integración

<ui-tag removable (ui-tag-remove)="onRemove(skill)">
  {{ skill }}
</ui-tag>

// schemas: [CUSTOM_ELEMENTS_SCHEMA] en el módulo consumidor
// Angular no reconoce eventos custom con guiones vía (evento) automáticamente
// si no coincide el casing — usá host listener o (ui-tag-remove) tal cual el nombre.
{{-- resources/views/components/... --}}
<ui-tag removable wire:key="skill-{{ $skill }}"
  x-on:ui-tag-remove="$wire.removeSkill('{{ $skill }}')">
  {{ $skill }}
</ui-tag>

Accesibilidad

  • El botón de quitar tiene aria-label="Quitar" — nunca queda como control sin nombre accesible.
  • El botón es navegable por Tab y activable con Enter/Space (es un <button> nativo).
  • Foco visible vía focus-visible:outline en el botón de quitar.
  • Área táctil del botón "×" es reducida — evitar como único punto de interacción en variantes táctiles sin padding adicional.
