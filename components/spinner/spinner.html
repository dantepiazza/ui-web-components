Spinner

Indicador de carga indeterminado. Para progreso con valor conocido, usá Progress Bar.

Uso básico

<ui-spinner></ui-spinner>

Tamaños

<ui-spinner size="sm"></ui-spinner>
<ui-spinner size="lg"></ui-spinner>

Props

PropTipoDefaultDescripción
size"sm" | "md" | "lg""md"Tamaño del anillo.
labelstring"Cargando"Texto accesible (visualmente oculto, vía sr-only) leído por lectores de pantalla.

Slots

No tiene slots.

Eventos

No emite eventos.

Integración

<ui-spinner *ngIf="loading"></ui-spinner>

// schemas: [CUSTOM_ELEMENTS_SCHEMA] en el módulo consumidor
{{-- resources/views/components/... --}}
<ui-spinner wire:loading></ui-spinner>

Accesibilidad

  • Expone role="status" y aria-live="polite" — anuncia el estado de carga sin robar el foco.
  • El texto de label es visualmente oculto pero legible por lectores de pantalla (patrón sr-only).
  • Respeta prefers-reduced-motion a nivel de sistema vía la animación estándar de Tailwind (no es obligatoria, pero queda pendiente añadir el media query explícito).
