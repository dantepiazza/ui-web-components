Forms

Input

Campo de texto con etiqueta, texto de ayuda y estado de error, sobre un <input> nativo.

Uso básico

<ui-input label="Nombre" placeholder="Tu nombre"></ui-input>

Con error

<ui-input label="Email" error="Ingresá un email válido"></ui-input>

Con ícono

<ui-input icon="search" placeholder="Buscar..."></ui-input>
<ui-input icon="eye" icon-position="end"></ui-input>

Reemplaza al viejo ui-input-icon — es decorativo (una pista visual, como una unidad o una lupa), no un botón interactivo. Para "buscar con botón de borrar" usá Input Search.

Props

PropTipoDefaultDescripción
labelstring""Etiqueta visible, asociada por id.
iconstring""Nombre de un ícono del set de Icon, decorativo dentro del campo.
icon-position"start" | "end""start"Lado del ícono dentro del campo.
typestring"text"Tipo nativo (text, email, password, number, etc).
valuestring""Valor del campo.
placeholderstring""Placeholder.
help-textstring""Texto de ayuda debajo del campo. Se oculta si hay error.
errorstring""Mensaje de error — activa el estado visual inválido.
disabledbooleanfalseDeshabilita el campo.
requiredbooleanfalseMarca el campo como requerido (asterisco visual + atributo nativo).
namestring""Nombre del campo en un <form>.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ value }En cada tecleo (además del input nativo, que también burbujea).

Integración

<ui-input label="Email" [value]="email" [error]="emailError"
  (ui-input)="email = $event.detail.value"></ui-input>
<ui-input label="Email" name="email"
  wire:model.blur="email" error="{{ $errors->first('email') }}"></ui-input>

Accesibilidad

  • <label for> asociado al input por id.
  • aria-invalid y aria-describedby apuntan al mensaje de error o de ayuda correspondiente.
  • El asterisco de required es visual; el atributo required nativo también está presente para validación del navegador y lectores de pantalla.
  • Contraste AA del borde de error (rose-400) y del texto de ayuda (zinc-500) sobre fondo blanco.
