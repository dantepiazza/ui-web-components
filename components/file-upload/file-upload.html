File Upload

Dropzone de arrastrar-y-soltar sobre un input de archivo nativo, con lista de seleccionados y quitar individual.

Uso básico

<ui-file-upload accept="image/*" multiple></ui-file-upload>

Props

PropTipoDefaultDescripción
acceptstring""Filtro de tipos de archivo, formato nativo ("image/*", ".pdf", etc).
multiplebooleanfalsePermite elegir/soltar varios archivos.
labelstring"Arrastrá archivos acá..."Texto del dropzone.
disabledbooleanfalseDeshabilita el control.

Slots

No tiene slots.

Eventos

EventoDetailCuándo se emite
ui-input{ files }Al agregar o quitar archivos. files es un array de File.

Integración

<ui-file-upload accept="image/*" multiple
  (ui-input)="files = $event.detail.files"></ui-file-upload>
<ui-file-upload accept="image/*" multiple
  x-on:ui-input="$wire.uploadFiles($event.detail.files)"></ui-file-upload>
// Livewire necesita $wire.upload() con su propio manejo de FormData para subir de verdad

Accesibilidad

  • El dropzone es un <label> asociado al input real (sr-only) — clickeable y activable por teclado (foco en el label + Enter abre el diálogo del navegador).
  • Cada archivo en la lista tiene su botón de quitar con aria-label incluyendo el nombre del archivo.
