Personalizar colores & modo oscuro

Los componentes no usan zinc/emerald directo — usan una paleta semántica respaldada por CSS custom properties (--ui-*). Redefinir esas variables re-tematiza toda la librería, incluso con el CSS ya compilado y sin recompilar.

Tokens

TokenPara quéDefault
base-50…950Escala neutra: texto, bordes, fondos, rellenos, disabledzinc
surfaceSuperficies elevadas: cards, inputs, modales, popovers, topbarwhite
brand-50…950Acento: botón primary, estados activos, focus rings, slider/progress= base
brand-fgTexto/ícono encima de un fondo brandwhite
success · warning · danger · info (+ -fg)Estados semánticos (callout, toast, validación, progress)emerald · amber · rose · blue

Cada token es rgb(var(--ui-TOKEN, <default>) / <alpha-value>): funciona la opacidad (bg-brand-600/10), cae al default si no lo definís, y los valores son canales RGB separados por espacio (24 24 27), no #hex.

Con el CSS compilado (dos tags)

Cargá tu :root después de ui-web-components.css:

:root {
  /* marca azul — solo el acento, el texto/neutro no se toca */
  --ui-brand-500: 59 130 246;
  --ui-brand-600: 37 99 235;
  --ui-brand-900: 30 58 138;
  --ui-brand-fg:  255 255 255;
}

El botón primary usa brand-900. Si tu marca es un mid-tone y no querés que quede oscuro, poné ese valor en el slot 900 — o pisá solo el botón: .ui-button.bg-brand-900 { background-color: #005ffe }.

Con tu propio build de Tailwind

Extendé theme.extend.colors con los mismos nombres (base, brand, surface, success…) y sumá los .js de la librería al content. El :root de referencia está en scripts/tailwind-input.css.

Modo oscuro

  • Disparador: el atributo global ui-theme-toggle en cualquier elemento, o window.__uiwc.setTheme('dark'|'light'). Persiste en localStorage.
  • Bajo .dark la escala base/brand se invierte y los estados se aclaran — todo componente que use bg-base-* se re-tematiza solo.
  • Si togglés .dark a mano: agregá una clase con transition: none !important, flipeá, forzá un reflow, sacala en el próximo frame — Chromium se queda con el color viejo si solo cambió la variable (crbug.com/1226629). ui-theme-toggle ya lo hace; la clase .uiwc-theme-switching viene en el CSS.
  • Personalizá el dark redefiniendo --ui-* dentro de tu propio .dark { … }.
