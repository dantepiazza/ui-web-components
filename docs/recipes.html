Confirmar antes de borrar

El patrón más común de todos, sin escribir un <template> a mano — UiDialog.confirm() (o window.__uiwc.confirm() si no importaste la clase) hace todo.

Eliminar postulante 
button.addEventListener('click', async () => {
  const ok = await window.__uiwc.confirm('¿Eliminar a Juan Pérez? No se puede deshacer.', {
    title: 'Eliminar postulante',
    confirmLabel: 'Eliminar',
    variant: 'danger',
  });
  if (ok) await fetch('/postulantes/1', { method: 'DELETE' });
});
